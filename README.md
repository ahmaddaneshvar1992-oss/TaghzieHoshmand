# 🥗 تغذیه هوشمند — اپلیکیشن اندروید تغذیه و کالری‌شماری فارسی

اپلیکیشن حرفه‌ای مدیریت وزن، کالری‌شماری و مشاور تغذیه هوشمند، **کاملاً فارسی و راست‌به‌چپ**، با طراحی مدرن بر اساس تصاویر مرجع (هدر سرمه‌ای منحنی، حلقه پیشرفت فیروزه‌ای، کارت‌های سفید گرد و نوار ناوبری شناور).

## 🎨 پالت رنگی سازمانی

| نقش | رنگ |
|---|---|
| اصلی (سرمه‌ای تیره) | `#0A2540` |
| ثانویه (فیروزه‌ای) | `#00B4D8` |
| موفقیت | `#10B981` |
| هشدار | `#F59E0B` |
| پس‌زمینه | سفید و خاکستری خیلی روشن |
| متن | سرمه‌ای تیره و خاکستری تیره |

فونت برنامه **وزیرمتن** (Vazirmatn) است که به‌صورت داخلی (res/font) همراه اپ عرضه شده و همه اعداد به فارسی نمایش داده می‌شوند. تاریخ‌ها شمسی است (ماژول اختصاصی JalaliDate).

## ✨ امکانات

### مدیریت پروفایل و اهداف
- ثبت‌نام محلی با رمز ۴ رقمی اختیاری + صفحه قفل
- آنبوردینگ ۵ مرحله‌ای (نام/جنسیت، سن/قد/وزن، سطح فعالیت، هدف وزن، خلاصه)
- محاسبه خودکار **BMI، BMR، TDEE** و کالری هدف (معادله Mifflin–St Jeor)
- اهداف ماکرو (پروتئین/کربوهیدرات/چربی) و هدف آب بر اساس وزن بدن
- صفحه پروفایل بدنی با خط‌کش BMI و نمودار وزن ۳۰ روزه

### ثبت و پیگیری غذا
- ثبت وعده‌ها: صبحانه، ناهار، شام، میان‌وعده با زبانه و جمع کالری هر وعده
- **پایگاه داده ۳۳۹ غذای ایرانی و بین‌المللی** (`assets/foods_fa.json`) با کالری و ماکرو در ۱۰۰ گرم و سهم استاندارد
- جستجوی غذا + فیلتر دسته‌بندی (۱۶ دسته با آیکون)
- افزودن **غذای شخصی** با هشدار اعتبارسنجی کالری/ماکرو
- **اسکن بارکد** با دوربین (ML Kit) و جستجوی بین‌المللی از Open Food Facts + ورود دستی
- ثبت سریع غذاهای پرمصرف و علاقه‌مندی‌ها
- برگه تنظیم مقدار (گرم) با محاسبه لحظه‌ای کالری و ماکرو
- **پیشنهاد جایگزین کم‌کالری‌تر** از پایگاه داده
- محاسبه کالری سهم بر اساس وزن کاربر

### برنامه غذایی
- **برنامه غذایی روزانه و هفتگی** ساخته‌شده از کالری هدف کاربر (۴ وعده، توزیع ۲۵/۳۵/۳۰/۱۰ درصد)
- جایگزینی هر آیتم برنامه با غذای مشابه از پایگاه داده (دکمه 🔄)
- علامت‌گذاری انجام‌شده و ثبت مستقیم در دفتر غذای همان روز

### هوش مصنوعی
- **چت‌بات فارسی تغذیه** با دانش غذاهای ایرانی؛ شناخت «وضعیت امروز» کاربر (کالری، ماکرو، آب، ورزش، وزن)
- **حالت دوگانه**: بدون پیکربندی، موتور آفلاین قاعده‌محور پاسخ می‌دهد؛ با پیکربندی سرویس سازگار با OpenAI (OpenAI، OpenRouter، Groq، Ollama و…) پاسخ‌ها از آن مدل می‌آید و در خطا خودکار به حالت آفلاین برمی‌گردد
- **تحلیل عکس غذا** با مدل بینایی (نیاز به سرویس پیکربندی‌شده) و تخمین کالری/ماکرو
- چیپ‌های پیشنهادی: برنامه هفتگی، کالری امروز، جایگزین غذا، وضعیت آب، پیشرفت وزن

### سلامت و فعالیت
- **آب روزانه**: حلقه پیشرفت + لیوان/بطری/پارچ و مقدار دلخواه + لیست ثبت‌ها
- **ورزش**: ۵۸ فعالیت با MET واقعی (Compendium of Physical Activities)، محاسبه کالری = MET × وزن × ساعت، ثبت قدم دستی
- **همگام‌سازی Health Connect** (جایگزین رسمی Google Fit در اندروید جدید): ثبت وزن، آب، کالری سوزانده و قدم با مجوز کاربر

### پیشرفت و آمار
- نمودار خطی وزن (۷/۳۰/۹۰ روز) با گرادیان و حباب مقدار
- نمودار میله‌ای کالری ۷ روز اخیر با خط هدف
- کارت‌های میانگین کالری، تغییر وزن ماه، روزهای موفق
- حلقه هدف قدم روزانه + خلاصه آب و ورزش
- **گالری عکس پیشرفت بدن** (قبل و بعد) با مقایسه دو عکس و تغییر وزن بین آن‌ها

### یادآورها
- یادآور وعده غذایی، آب و سنجش وزن با **AlarmManager + نوتیفیکیشن** (حتی با بسته بودن اپ)
- انتخاب روزهای هفته (شنبه تا جمعه) و زمان دلخواه
- یادآورهای پیش‌فرض در پایان آنبوردینگ ساخته می‌شوند

### داده و خروجی
- **کاملاً آفلاین**: همه داده‌ها در Room روی خود گوشی
- **خروجی PDF** فارسی راست‌به‌چپ با سرصفحه سرمه‌ای (ساخته‌شده با PdfDocument، بدون کتابخانه خارجی)
- **خروجی Excel واقعی (.xlsx)** راست‌به‌چپ با ۴ شیت (ساخته‌شده بدون POI، خروجی ZIP/Open XML سبک) + خروجی CSV سازگار با اکسل فارسی
- **پشتیبان‌گیری و بازیابی کامل** در قالب JSON (فعالیت‌ها، وزن، آب، ورزش، غذاهای شخصی، برنامه، یادآورها)
- **دارک مود** کامل (سیستم/روشن/تیره)

## 🖥 صفحات اپلیکیشن

ورود/ثبت‌نام → آنبوردینگ → **داشبورد** (حلقه کالری، وزن/قد/BMI، عملیات سریع، ماکروها) → **ثبت وعده** → **جستجوی غذا** → **برنامه غذایی** → **چت هوش مصنوعی** → **پیشرفت و آمار** → **پروفایل بدنی** → **آب** → **ورزش** → **گالری پیشرفت** → **اسکن بارکد** → **یادآورها** → **تنظیمات**

## 🔧 ساخت و اجرا

### پیش‌نیازها
- Android Studio Koala یا جدیدتر (یا فقط JDK 17+ و Android SDK 35)
- حداقل API 26 (اندروید ۸) — هدف API 35

### با Android Studio
1. پروژه را باز کنید (پوشه `TaghzieHoshmand`)
2. منتظر Sync بمانید (Gradle 8.9 و AGP 8.5.2 به‌صورت خودکار دانلود می‌شوند)
3. `Run ▶` روی دستگاه یا شبیه‌ساز

### با خط فرمان
```bash
./gradlew :app:assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

### ساخت APK امضاشده Release
در Android Studio: `Build > Generate Signed Bundle/APK > APK` و یک keystore بسازید (تنظیمات `signingConfig` در `app/build.gradle.kts`).

## 🤖 پیکربندی هوش مصنوعی (اختیاری)

در **تنظیمات → هوش مصنوعی** سه مقدار را وارد کنید:

| فیلد | مثال |
|---|---|
| آدرس پایه API | `https://api.openai.com/v1` یا `https://openrouter.ai/api/v1` |
| کلید API | کلید سرویس شما |
| نام مدل | `gpt-4o-mini` یا `openai/gpt-4o-mini` |

- چت‌بات و تحلیل عکس از همین سرویس استفاده می‌کنند (فرمت OpenAI Chat Completions).
- بدون پیکربندی یا در قطعی اینترنت، موتور آفلاین فارسی پاسخ می‌دهد و پیام خطا شفاف نمایش داده می‌شود.
- کلید فقط در DataStore خود دستگاه ذخیره می‌شود و جایی ارسال نمی‌شود.

## 🗃 معماری و ساختار

```
app/src/main/java/ir/taghziehoshmand/app/
├── TaghzieApp.kt          # اپلیکیشن + کانتینر وابستگی‌ها (DI دستی)
├── MainActivity.kt        # فارسی‌سازی و RTL + تم
├── core/                  # Format (اعداد فارسی)، JalaliDate (تقویم شمسی)، HealthCalc (BMI/BMR/TDEE)
├── data/
│   ├── model/Entities.kt  # موجودیت‌های Room (غذا، وعده، آب، ورزش، وزن، عکس، چت، برنامه، یادآور، قدم)
│   ├── db/                # DAOها و دیتابیس
│   ├── prefs/UserPrefs.kt # پروفایل و تنظیمات (DataStore + kotlinx.serialization)
│   └── repo/FoodCatalog.kt# بارگذاری پایگاه داده غذا/ورزش از assets
├── ai/                    # AiEngine، AiHttp (سازگار با OpenAI)، OfflineExpert (قاعده‌محور)، MealPlanner، Prompts
├── export/                # PdfExporter، MiniXlsx (xlsx بدون POI)، ExportManager (PDF/Excel/CSV/پشتیبان)
├── service/               # ReminderScheduler (AlarmManager)، OpenFoodFacts
├── sync/                  # HealthConnectSync
└── ui/
    ├── theme/             # رنگ‌ها، فونت وزیرمتن، تم روشن/تیره
    ├── components/        # CurvedHeader، RingProgress، LineChart، BarChart و…
    └── screens/           # ۱۴ صفحه اپلیکیشن
```

**تکنولوژی‌ها**: Kotlin 2.0، Jetpack Compose (Material 3)، Room، DataStore، Navigation-Compose، CameraX + ML Kit Barcode، Health Connect، AlarmManager، Coil، kotlinx-serialization. بدون Hilt و بدون کتابخانه نمودار خارجی (نمودارها با Canvas نوشته شده‌اند).

## ⚠️ نکات و محدودیت‌ها

- تحلیل عکس غذا و پاسخ‌های چت پیشرفته به یک سرویس AI نیاز دارد؛ حالت آفلاین جایگزین آن است.
- جستجوی بارکد بین‌المللی نیاز به اینترنت دارد (Open Food Facts)؛ داده‌های پایگاه غذا و همه ثبت‌ها آفلاین‌اند.
- Google Fit APIهای قدیمی منسوخ شده‌اند؛ همگام‌سازی از مسیر رسمی **Health Connect** پیاده‌سازی شده است.
- مقادیر تغذیه‌ای پایگاه داده تقریبی و برای اطلاع‌رسانی عمومی است؛ برای رژیم درمانی به متخصص تغذیه مراجعه کنید.
